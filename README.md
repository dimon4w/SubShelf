# SubShelf

Трекер подписок и trial-периодов для Android. Показывает, какие подписки активны, когда и сколько спишут, и напоминает заранее, чтобы пробный период не превратился в платный незаметно для вас.

Все данные хранятся только на телефоне: сервер, аккаунт и интернет не нужны.

## Возможности

- **Статусы.** Trial, активная или отменённая подписка, цена, валюта и период списания.
- **Сводка.** Сколько денег спишут по неотменённым trial и сколько уходит в месяц на активные подписки.
- **Фильтр и выбор.** Переключатель «Все / Trial / Активные / Отменённые» и режим «Выбрать» для массовых действий.
- **Напоминания.** Уведомления Android за 3 дня, за 1 день и в день списания в выбранное время.
- **Отмена.** Кнопка «Как отменить» открывает ссылку сервиса (или поиск), кнопка «Отменил» помечает подписку. Само приложение подписки не отменяет: это делается в сервисе.
- **Резервная копия.** Экспорт в JSON через «Поделиться» и восстановление из копии.
- **Оформление.** Монохромная система MediaShelf, «жидкое стекло» с преломлением, светлая и тёмная тема, русский и английский язык.

## Установка

1. Откройте [последний релиз](../../releases/latest) на телефоне.
2. Скачайте файл `SubShelf-*.apk` и откройте его.
3. Разрешите установку из этого источника, если Android попросит.

Новые версии ставятся поверх старых, данные сохраняются: все релизы подписаны одним ключом.

## Разработка

```bash
npm install
npm run dev          # веб-версия в браузере
npm run check        # типы, тесты, форматирование
npm run android      # сборка и синхронизация с android/
```

Стек: Vite, React 19, Tailwind CSS 4, Motion, Capacitor 8 (Preferences, Local Notifications, Share, Browser, Status Bar).

## Сборка APK

Каждый пуш в `main` запускает GitHub Actions: проверки, сборку веб-части, генерацию иконок из `assets/`, сборку подписанного APK и публикацию релиза `v0.1.<номер сборки>`.

Для подписи нужны секреты репозитория:

| Секрет                      | Что внутри                      |
| --------------------------- | ------------------------------- |
| `ANDROID_KEYSTORE_B64`      | ключ подписи PKCS#12 в base64   |
| `ANDROID_KEYSTORE_PASSWORD` | пароль ключа (алиас `subshelf`) |

Ключ не хранится в репозитории. Если его потерять, следующую версию придётся ставить с удалением старой.
