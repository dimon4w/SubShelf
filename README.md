# SubShelf

Трекер подписок и trial-периодов для Android. Показывает, какие подписки активны, когда и сколько спишут, и напоминает заранее, чтобы пробный период не превратился в платный незаметно для вас.

Все данные хранятся только на телефоне: сервер и аккаунт не нужны. Интернет нужен только для поиска иконок.

## Возможности

- **Две группы.** Пробные и активные подписки отдельно, у каждой цена, валюта (по умолчанию USD), период и одна дата: конец пробного или следующее списание.
- **Напоминания.** Уведомление Android за выбранное число дней до списания и в сам день, в выбранное время.
- **Иконки сами.** Пишете название, например «Netflix» или «Aqua Voice», и иконка подбирается: сначала из встроенного каталога без интернета, потом по названию в сети. В сеть уходит только название сервиса; это можно выключить.
- **Профиль и история.** Отменённые подписки уходят в историю с датой отмены, их можно вернуть. Там же сводка за месяц и год и настройки.
- **Оформление.** Строгий чёрно-белый стиль без «стекла», светлая и тёмная тема, акцентный цвет на выбор. Ни одна подпись не переносится на вторую строку на любом телефоне.
- **Резервная копия.** Экспорт в JSON через «Поделиться» и восстановление из файла. Данные версии 0.1 переносятся автоматически.

## Установка

1. Откройте [последний релиз](../../releases/latest) на телефоне.
2. Скачайте файл `SubShelf-*.apk` и откройте его.
3. Разрешите установку из этого источника, если Android попросит.

Новые версии ставятся поверх старых, данные сохраняются: все релизы подписаны одним ключом.

## Разработка

```bash
npm install
npm run dev          # веб-версия в браузере
npm run check        # типы, тесты, форматирование
npm run android      # сборка и синхронизация с android/
```

Стек: Vite, React 19, Tailwind CSS 4, Capacitor 8 (Preferences, Local Notifications, Share, Status Bar).

## Сборка APK

Каждый пуш в `main` запускает GitHub Actions: проверки, сборку веб-части, генерацию иконок из `assets/`, сборку подписанного APK и публикацию релиза `v0.1.<номер сборки>`.

Для подписи нужны секреты репозитория:

| Секрет                      | Что внутри                      |
| --------------------------- | ------------------------------- |
| `ANDROID_KEYSTORE_B64`      | ключ подписи PKCS#12 в base64   |
| `ANDROID_KEYSTORE_PASSWORD` | пароль ключа (алиас `subshelf`) |

Ключ не хранится в репозитории. Если его потерять, следующую версию придётся ставить с удалением старой.
